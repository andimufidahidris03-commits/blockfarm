# BlockFarm

Aplikasi blockchain untuk pencatatan rantai pasok hasil pertanian.

## Requirement

- Docker Desktop
- Git

## Menjalankan Project

Clone repository:

```bash
git clone https://github.com/andimufidahidris03-commits/blockfarm.git
```

Masuk ke folder:

```bash
cd blockfarm
```

Jalankan Docker:

```bash
docker compose up --build
```

Buka browser:

```
http://localhost:8080
```

## Tech Stack

- React + Vite
- TypeScript
- Hardhat
- Solidity
- Docker
